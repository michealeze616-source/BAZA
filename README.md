# BAZA

**Everything you need. All in one place.**

BAZA is a Nigeria-first general marketplace concept for discovering products, services, shops, and local deals.

## Stack
- React + TypeScript + Vite
- Supabase planned for authentication, database, storage, and messaging
- Deploy-ready for Vercel

## Local development
```bash
npm install
npm run dev
```

## Supabase setup
Copy `.env.example` to `.env.local` and add your Supabase URL and anon key. Auth and data features are progressively wired as backend setup is completed.
